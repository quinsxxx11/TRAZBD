# 📅 Оффлайн-трекер привычек и рутинных задач

Одностраничное веб-приложение (SPA) для ведения дневника привычек, работающее полностью оффлайн. Благодаря встроенному Python-серверу, данные **автоматически** сохраняются в файл `data/tracker_backup.db` на вашем компьютере при каждом изменении.

## 🚀 Как запустить проект

Для работы приложения требуется установленный Python 3.

1. Дважды кликните по файлу **`start.bat`**.
2. Скрипт запустит локальный сервер, который будет отдавать файлы сайта и одновременно записывать данные в `.db` файл.
3. Браузер автоматически откроется по адресу `http://localhost:8000`.
4. Для остановки сервера просто закройте окно консоли.

## 🛠 Функционал

* **Тёмный интерфейс:** Стильный дизайн с неоновыми акцентами в стиле мобильных приложений.
* **Календарь:** Адаптивная сетка на месяц с навигацией. Дни с выполненными привычками подсвечиваются голубым.
* **Привычки:** Добавление карточек с валидацией.
* **Числовые привычки:** Возможность указать цель (например, "Выпить воды - 8 раз"). При клике появится окно ввода.
* **Автосохранение:** Данные мгновенно пишутся в `data/tracker_backup.db` (бинарный формат).
* **Экспорт/Импорт:** Резервное копирование и восстановление файла базы данных.
* **Статистика:** Отображается текущая серия дней подряд, общее количество задач и мотивация.
